# Equipment categories and models

All equipment on EquipmentExchange is described from a shared equipment knowledge base. This keeps descriptions consistent: two suppliers renting the same model show the same specifications.

## Categories

Every model belongs to a category, the broad type of machine. Examples of categories include excavators, mini excavators, wheel loaders, backhoe loaders, telehandlers and rollers. The list of categories is maintained by EquipmentExchange.

## Models

Within a category, a model is a specific machine from a specific manufacturer, such as a particular 20-tonne excavator. When a supplier creates a listing, they choose the model from the knowledge base rather than typing a description.

## Specifications

Each model carries specifications, for example:

- operating weight
- engine power
- maximum digging depth and reach
- maximum lift height and lift capacity
- bucket capacity
- drum width (for rollers)
- transport length
- engine model

Which specifications apply depends on the category. Drum width matters for a roller but not for an excavator.

Specifications come from the knowledge base, not from the supplier. A supplier cannot change what a machine is: they choose the model, and the model's specifications follow.

## Unknown values

Not every value is known for every model. When a value is not known, it is shown as not known. It is never guessed or filled in with an estimate. Builders should ask the supplier if a missing value matters for their job.

## Your own machines

A listing describes a model. The individual machines behind it are recorded separately by the supplier: each machine has its own model year, condition and identifiers such as a serial number. The model's specifications describe what the machine is; the machine's own details describe that particular unit.
