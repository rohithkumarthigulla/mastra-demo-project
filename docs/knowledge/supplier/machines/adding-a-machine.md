# Adding a machine

Add a machine for each physical unit you want to rent out. A listing needs at least one active machine before it can be published, so adding a machine is usually the step that lets a new listing go live.

## Before you start

You need:

- **A listing** for the machine's model. The machine is added to that listing. If you do not have one yet, create the listing first.
- **A yard** where the machine is kept. If you do not have one yet, add the yard first. See "Yards".

## What to enter

| Field       | What to enter                                             |
| ----------- | --------------------------------------------------------- |
| Listing     | the listing for this machine's model                      |
| Yard        | where the machine is kept                                 |
| Model year  | the year the machine was made                             |
| Condition   | New, Excellent, Good, Fair or Poor                        |
| Identifiers | such as the serial number, so you can tell machines apart |

Each machine belongs to exactly one listing and one yard.

## Choosing the condition

Be honest about condition. Builders rely on it when choosing equipment, and an accurate description avoids disputes when the machine arrives on site.

- **New:** unused or nearly so.
- **Excellent:** little wear, everything works as it should.
- **Good:** normal wear for its age, fully working.
- **Fair:** visible wear, working but may need attention.
- **Poor:** heavy wear; usable only for some jobs.

## What you do not enter

You do not enter specifications such as operating weight or engine power. They come from the equipment knowledge base for the listing's model. A supplier cannot change what a machine is.

## After adding

The new machine is active and available, except on dates you block. If its listing was a draft waiting for a machine, you can now publish it.

If the machine has dates when it cannot be rented, such as planned maintenance, record them as blocks straight away. See "Blocking dates on a machine".

## Common questions

**I have three of the same model. Do I need three listings?** No. Add three machines to one listing.

**I picked the wrong yard.** You can change it. See "Editing a machine".
