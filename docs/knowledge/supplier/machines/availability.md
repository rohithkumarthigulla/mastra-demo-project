# Machine availability

Availability tells you, and the assistant, which of your machines can be rented on which dates. Keeping it accurate means you only get requests you can actually fulfil.

## What makes a machine unavailable

An active machine is available unless one of these applies on a given date:

- **It is blocked.** You have recorded a block for Maintenance, Transport or Held back covering that date. See "Blocking dates on a machine".
- **It is retired.** A retired machine is never available, on any date.

Bookings also matter. A rental is committed once a builder accepts a quote and a booking is created. Before then, a request or a quote does not reserve the machine.

## Requests do not reserve machines

When a builder sends a request, or you send a quote, the machine is not held. Nothing is committed until the builder accepts a quote. Two builders can ask about the same dates; the machine is committed only when one of them accepts a quote and the booking becomes `CONFIRMED`.

So before you send a quote, check that a suitable machine is free for the requested dates.

## Keeping availability accurate

- **Record blocks early.** As soon as you know a machine will be in the workshop or held back, block those dates.
- **Lift blocks you no longer need.** Lifting a block frees the dates straight away.
- **Retire machines that have left your fleet.** Retired machines are never available, so they will not appear as options.
- **Keep the yard right.** Each machine belongs to one yard. The yard shows where the machine is kept, which matters when you plan transport.

## Checking availability

To see whether you can take on a rental, look at the active machines on the listing and check that at least one has no block and no booking covering the requested dates. You can also ask the assistant, for example: "Is any machine on my excavator listing free from the 10th to the 20th?" The assistant answers from your own data.

## Common questions

**Does making a listing Inactive change machine availability?** No. It hides the listing from builders so they cannot send new requests. The machines and their blocks stay as they are.

**Can a block overlap a booking?** Plan blocks around existing bookings so you can still deliver what you agreed.
