# Blocking dates on a machine

A block marks a machine as unavailable for a date range. Use it whenever a machine cannot be rented for a while, so you are not asked to supply it on those days.

## Reasons for a block

Every block has one of three reasons:

| Reason      | Use it when                                                      |
| ----------- | ---------------------------------------------------------------- |
| Maintenance | the machine is being serviced or repaired                        |
| Transport   | the machine is being moved, for example between yards            |
| Held back   | you are keeping the machine for your own use or any other reason |

## Creating a block

Choose the machine, the reason, and the start and end dates. The machine is unavailable on every date in that range.

## Blocks cannot overlap

Blocks on the same machine cannot overlap. If a machine is already blocked from the 5th to the 10th, you cannot add another block on that machine that covers any of those dates.

If you need a longer block, lift the existing one and create a new block for the full range. Different machines have separate blocks: blocking one excavator does not affect your other excavators.

## Lifting a block

When a block is no longer needed, for example because a repair finished early, lift it. Lifting a block frees the dates, and the machine becomes available again on those days.

## Blocks compared with retiring

A block is temporary. When it ends or is lifted, the machine is available again.

Retiring is permanent. A retired machine is kept for history but is never available. Retire a machine only when it has left your fleet for good. See "Editing a machine".

## Using the assistant

You can ask the assistant to block or lift dates, for example: "Block the second excavator for maintenance from Monday to Wednesday." It will describe the block it is about to create (the machine, the reason and the dates) and ask you to confirm. Nothing changes until you confirm.

## Common questions

**I tried to add a block and it was refused.** The usual reason is an overlap with an existing block on the same machine. Check that machine's blocks and adjust the dates.

**Does a block affect quotes I have already sent?** A block records when the machine is unavailable. Check your sent quotes and bookings before blocking dates you may have promised to a builder.
