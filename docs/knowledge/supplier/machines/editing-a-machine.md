# Editing a machine

Keep your machines' details up to date so that builders and your own team can rely on them.

## What you can change

- **Yard.** Move the machine to another of your yards when you relocate it.
- **Condition.** Update it as the machine wears or after a major repair. The options are New, Excellent, Good, Fair and Poor.
- **Identifiers.** Correct a mistyped serial number or other identifier.
- **Model year.** Correct it if it was entered wrongly.

A machine always belongs to exactly one yard, so moving it to a new yard replaces the old one.

## What you cannot change

**Specifications.** Operating weight, engine power, digging depth and similar values come from the equipment knowledge base for the model. They are the same for every machine of that model, and a supplier cannot change them.

**What the machine is.** A machine belongs to a listing for one model. If the machine is actually a different model, it is in the wrong listing. Retire the incorrect record and add the machine to a listing for the correct model.

If a specification looks wrong or shows as not known, it is a matter for the knowledge base, not something to work around by editing the machine.

## Retiring a machine

When a machine leaves your fleet for good, retire it instead of deleting it.

- A retired machine is kept for history, so past rentals still show which machine was used.
- A retired machine is never available for rent.
- A retired machine does not count towards the active machine a listing needs to be published.

If a listing's only active machine is retired, that listing no longer has a machine builders could rent. Add another machine, or make the listing Inactive so builders do not send requests you cannot fulfil.

## Temporary unavailability is not retirement

If a machine is unavailable only for a while (in the workshop, being moved, or held for your own use), do not retire it. Record a block for those dates instead. Blocks can be lifted, and the dates become available again. See "Blocking dates on a machine".

## Common questions

**Will editing a machine change existing bookings?** Changing details like condition or identifiers updates the record. Bookings and quotes keep their own agreed terms.
