# Publishing a listing

Publishing a listing makes it Active, so builders can find it and send rental requests. Until then it is a Draft and only you can see it.

## The requirement

A listing needs at least one active machine before it can be published. An active machine is one you own, attached to this listing and not retired.

If you try to publish a listing without one, publishing is refused. Add a machine first (see "Adding a machine"), then publish again.

## What changes when you publish

- The listing status becomes **Active**.
- Builders can see the listing, its photos and its specifications.
- Builders can send rental requests against it.

Publishing does not commit you to anything. A rental request only asks for a price. Nothing is agreed until you send a quote and the builder accepts it.

## Taking a listing down

If you want to stop receiving requests, make the listing **Inactive**. An Inactive listing is hidden from builders, just like a draft, but it keeps its details, photos and machines so you can make it Active again later.

Making a listing Inactive does not cancel bookings that already exist. Bookings follow their own lifecycle; see "The booking lifecycle".

## Listing statuses at a glance

| Status   | Who can see it   | Builders can request |
| -------- | ---------------- | -------------------- |
| Draft    | only you         | no                   |
| Active   | you and builders | yes                  |
| Inactive | only you         | no                   |

## Before you publish: a checklist

- The model is correct. Specifications come from the model and you cannot edit them.
- At least one active machine is attached.
- Photos show the real equipment (up to 10; JPEG, PNG or WebP; up to 8 MB each).
- Your price per day is up to date, since it is the basis for your quotes.
- Your machines' blocked dates are recorded, so you do not get requests for days you cannot supply. See "Blocking dates on a machine".

## Common questions

**Why can't I publish?** The most common reason is that the listing has no active machine. Retired machines do not count.

**Will builders see my draft changes?** Builders see only Active listings.
