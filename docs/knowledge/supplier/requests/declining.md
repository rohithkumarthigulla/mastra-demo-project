# Declining a request

You do not have to take every rental request. When a request arrives with the status `PENDING`, you can accept it or decline it. Declining ends the request.

## When to decline

Common reasons to decline include:

- **No machine is free.** Every machine on the listing is blocked or booked for the requested dates.
- **You cannot deliver.** The site is too far away, or you cannot arrange transport in time.
- **The dates do not work.** The rental period is too short or too long for you to supply.
- **The job does not suit the equipment.** The builder's message describes work the machine is not right for.

## What declining does

- The request ends. You do not prepare a quote for it.
- No booking is created and nothing was committed. A request never commits either side; only accepting a quote does.

If the builder still needs equipment, they can send a new request, for example for different dates.

## Decline instead of ignoring

If you cannot take a rental, decline the request rather than leaving it `PENDING`. Builders are waiting for an answer, and a clear decline lets them look elsewhere quickly.

## Alternatives to declining

Before declining, consider whether you could meet the builder's need in another way:

- **Another machine.** If one machine is blocked, another machine on the same listing may be free.
- **Lift a block.** If a machine is held back but you could release it, lifting the block frees the dates.
- **Price the difficulty.** If delivery is the issue, you can accept the request and include a `TRANSPORT` line in your quote. The builder then decides whether the price works for them.

## After you have sent a quote

Declining applies to requests. If you have already accepted a request and sent a quote, that quote is locked: it cannot be edited. Whether a rental happens is then up to the builder, who can accept the quote.

## Using the assistant

You can ask the assistant to decline a request. It will tell you which request it is about to decline and ask you to confirm. Nothing changes until you confirm.

## Common questions

**Can I undo a decline?** Declining ends the request. If you change your mind, the builder can send a new request.
