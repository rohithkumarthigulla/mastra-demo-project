# EquipmentExchange

A construction-equipment rental marketplace: suppliers list equipment, and builders request it for a date range.

## Planned stack

- `apps/api`: NestJS + Fastify + Drizzle on PostgreSQL
- `apps/client`: Expo (iOS, Android, web)
- `packages/contracts`: Zod schemas shared by the api and the client

The project is built issue by issue. The first issue creates the folder structure; later issues fill it in.
